工作区与认证

普通客户端`X-Workspace-Id` 指定工作区
强制切换`?force_workspace=ws_xxx`
管理员面`/admin-api/*` 与 `/api/*` 需要管理员认证

验证码接口

GET /client-api/mail-code?email=user@example.com&live=1&provider=auto
POST /client-api/mail-code
GET /api/mail-code?email=user@example.com&live=1

返回当前工作区指定邮箱的最新验证码；`live=1` 时会先触发一次取信，再从缓存中提取最新 6 位验证码。

核心接口

邮件缓存`GET /client-api/messages`
删除缓存邮件`POST /client-api/messages/delete`
后台取信任务`POST /client-api/fetch-start` / `GET /client-api/fetch-status`
订阅核验`POST /client-api/accounts/check-subscription`
工作区找回`GET/POST /client-api/workspaces/*`
管理员 JWT 提取`POST /admin-api/extract-jwts`
