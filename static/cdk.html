CDK 取码 / 兑换页

这个页面预留给独立 CDK 服务。适合单独绑域名，对外只暴露 CDK 兑换和查询，不和主线收件箱混在一起。

定位 插件独立部署，主项目只保留入口和边界说明。
⌘ 用户任务页 独立用户任务大厅，对应 `cdk-task-center` 的 `/`。 ⌘ CDK 兑换页 独立兑换入口，对应 `cdk-task-center` 的 `/redeem.html`。 ⌗ 管理员页 独立后台，对应 `cdk-task-center` 的 `/admin.html`。 ⌁ 健康检查 独立服务探针，对应 `cdk-task-center` 的 `/healthz`。
⌁ 独立 API CDK 服务建议维持独立 API、独立任务状态和独立管理面，不直接耦合主线工作区数据。
⇄ 对接方式 主项目通过插件中心挂入口；如果后续需要，只做 URL 级跳转或结果级回调，不混状态机。
